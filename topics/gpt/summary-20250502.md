
# Project Summary: Custom Trading Infrastructure with IBKR

## Architecture Overview
- **IBKR Gateway Docker**: Containerized official Interactive Brokers Gateway.
- **Adapter API (FastAPI)**: Talks to IBKR Gateway locally; exposes a clean REST API.
- **Strategy Worker(s)**: 
  - Runs trading strategies (live or backtest mode).
  - Backtest mode uses Yahoo Finance historical data.
- **Result Aggregator (FastAPI + PostgreSQL)**:
  - Collects strategy results, trades, P&L, etc.
  - API to serve the Frontend.
- **Frontend UI (Next.js)**:
  - Displays live/backtest results, orders, and charts.
  - Communication via REST APIs.

## Technologies
- **Backend**: Python (FastAPI, SQLAlchemy, IB_insync)
- **Frontend**: React (Next.js 14)
- **Database**: PostgreSQL (via Docker)
- **Infrastructure**: Docker Compose (local), Kubernetes (Kind for dev)
- **Backtest Data**: Yahoo Finance fetcher integrated
- **Control Tools**: Makefile, install scripts

## Key Features
- Modular Microservice Architecture
- Easy switch between Backtest and Live mode
- Scalable to multiple strategy workers
- Frontend dashboard for real-time or backtest result visualization
- Kubernetes-ready for future cloud deployment

## How to Run
```bash
# Install required tools (Docker, kubectl, kind)
bash install-tools.sh

# Start local stack
make start-local

```
